The "TRACKBLEND" project combines multiple tracking modules into a single platform, enabling users to efficiently manage their daily activities, monitor expenses, and maintain health records through an easy-to-use interface.The first module, "TASK MANAGEMENT SYSTEM" was designed to help users organize and track their daily tasks effectively. The system allows users to create, update, and delete tasks, set priorities, and monitor task completion status. This improves productivity and helps users manage their schedules efficiently through a centralized task management interface.
The second module, "EXPENSE TRACKER" was developed to simplify personal financial management. The proposed system enables users to add, edit, and categorize expenses while maintaining detailed expense records. The application provides an organized view of spending patterns, helping users monitor and control their financial activities efficiently.
The third module, "CALORIE TRACKING SYSTEM" was implemented to support users in maintaining healthy lifestyle habits. The system allows users to track food items and monitor calorie intake on a daily basis. This feature helps users maintain awareness of their nutritional consumption and supports better health management.
The complete system was developed using technologies such as *Python, Django, SQLite, HTML, CSS, and Bootstrap*. Django was used for backend development and database management, while HTML, CSS, and Bootstrap were used to create responsive and user-friendly interfaces. SQLite was used as the database for storing user information, task details, expense records, and calorie tracking data. The integrated platform provides a simple, efficient, and centralized solution for managing productivity, expenses, and health-related activities.
